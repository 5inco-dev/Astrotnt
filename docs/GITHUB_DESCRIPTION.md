# GitHub description suggestion

Astrotnt is a Godot 2D artillery game focused on local PvP combat, progression systems, equipment, tactical terrain destruction and mobile-friendly UX. The project is structured around a server-authoritative architecture for future backend integration with Spring Boot and PostgreSQL.
